# T3 Code

Read this when you run `/lgtm` inside T3 Code.

- **Link** the PR to the thread with `link_pull_request` as soon as it exists.
- **Watch** with `watch_pull_request` after your push (step 3). Push first, then watch, then end your turn. It wakes you on PR changes.
- **Unwatch** with `unwatch_pull_request` before you stop (step 5).
- **Read, comment, merge, and re-run checks** with the `pull_request_*` tools, `ci_logs`, and `ci_rerun` when they are listed. Use them instead of `gh`.
